# Vampires in New York

Interactive comic reader for James Marston's story.

## Run it

```bash
npm install
npm run dev      # dev server with live reload, opens the comic reader
npm run build    # production build into dist/
npm run preview  # serve the production build locally
```

## Layout

- `html/` pages (the reader is `html/comicReader.html`)
- `scss/` styles
- `public/js/` reader scripts
- `public/json/imagePaths.json` panel layout, narration text and audio per page
- `public/assets/` panel art, animations and sound
